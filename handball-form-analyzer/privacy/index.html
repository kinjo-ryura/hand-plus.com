プライバシーポリシー

対象: シュート改善（HandballFormAnalyzer）
最終更新日: 2026年10月18日

シュート改善（以下「本アプリ」）は、ユーザーのプライバシーを尊重します。本ポリシーは、本アプリにおける情報の取り扱いについて説明します。

1. 収集する情報

開発者が、ユーザーの個人情報を自ら収集することはありません。本アプリで撮影した動画、動画から求めた体の動き（骨格）のデータ、ゴールの位置、保存したフォーム、端末の名前、端末ごとに作る ID、前につないだもう 1 台の iPhone の ID と名前はすべてユーザー自身の端末内に保存され、開発者のサーバーへ送信されることはありません（開発者はサーバーを運用していません）。端末ごとに作る ID は、本アプリを初めて使うときにランダムに作る値で、端末の機種や電話番号などとは関係がありません。

本アプリには、撮影した録画（動画、撮影時のカメラの位置と向き、保存したフォーム。2 台で撮った録画は、相手の動画と相手の端末の ID も含みます）や 3D の画像を、ユーザー自身の操作で書き出して共有する機能があります。書き出したデータは、ユーザーが共有の画面で選んだ送り先（写真、ファイル、AirDrop、メッセージアプリなど）にだけ渡ります。本アプリが自動で外部へ送ることはありません。

2. 端末の機能の利用

  • カメラ: ゴールの位置合わせとシュートの撮影に使います。動画から体の動きを求める処理は、端末内で行います
  • ローカルネットワーク: 近くのもう 1 台の iPhone を探してつなぎ、2 台で撮った録画を送り合うために使います（次節）
  • 写真（追加のみ）: 撮った動画と 3D の画像を、ユーザーの操作で写真に保存するために使います。写真を読み取ることはありません

3. 通信先

本アプリは、インターネット上のサービスと通信しません。

撮影画面を開いている間は、近くで本アプリの撮影画面を開いているもう 1 台の iPhone を、Wi-Fi や Bluetooth を通じて探します。このとき、ユーザーが本アプリで設定した端末の名前（未設定の場合は「iPhone」）と、端末ごとに作る ID、前につないだ相手の ID が、近くで本アプリの撮影画面を開いている端末から見えます。

もう 1 台とつながると、2 台の間で直接通信します。やり取りするのは、撮影した動画と撮影時のカメラの位置と向き、2 台の録画を組にするための撮った時刻と 2 台の時計の差を測るための時刻、アプリのバージョンと端末ごとに作る ID です。通信は暗号化されます。

初めての相手とは、ユーザーが接続の画面で相手を選ぶか、届いた招待を承認したときにだけつながります。つながった相手の ID と名前は端末に残り、次からは 2 台とも撮影画面を開いて近づけるだけで自動でつながります。残すのは最後につないだ 1 台だけです。

4. 第三者への提供

開発者が、ユーザーのデータを第三者に提供・販売することはありません（開発者はユーザーのデータを保有していません）。

ただし、本アプリを TestFlight（Apple のベータ版配布の仕組み）で試験配布している間は、Apple が TestFlight を通じてクラッシュの情報や利用状況（端末の機種・iOS のバージョンなど）、ユーザーが TestFlight から送ったフィードバックを開発者に提供します。取り扱いは Apple のプライバシーポリシー に従います。

5. 解析・広告・トラッキング

本アプリには、解析ツールや広告 SDK を組み込んでいません。開発者が本アプリの利用状況を計測することはありません。

本ページを含むウェブサイト hand-plus.com では、閲覧状況を把握するためにアクセス解析（Cloudflare Web Analytics）を利用しています。Cookie を使用せず、個人を特定できる情報は取得しません。詳細は ハンド記録のプライバシーポリシー の「4. 解析・広告・トラッキング」をご覧ください。

6. 子供のプライバシー

本アプリは、13 歳未満の子供から個人情報を意図的に収集することはありません。

7. ユーザーデータの削除

本アプリのデータはすべて端末内に保存されています。アプリを削除することで、関連するすべてのデータが端末から削除されます。2 台で撮影した場合、もう 1 台へ送られた動画はその端末に残るため、それぞれの端末で削除してください。

前につないだ相手の ID と名前は、その相手とつながっている間に接続の画面の「切断」を押すと、端末から消えます。

共有の機能で書き出したデータは、書き出し先（写真、ファイル、送り先の端末やサービス）に残ります。アプリを削除しても消えないため、それぞれの書き出し先で削除してください。
