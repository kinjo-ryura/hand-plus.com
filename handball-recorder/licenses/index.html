対象: ハンド記録の iOS アプリ／Android 版／このサイトの試合データデモ（WebAssembly）

集計コア（handball-toolkit）

ハンド記録の試合集計は、オープンソースの集計コア handball-toolkit（MIT ライセンス）で動いています。このサイトの試合データデモと試合・ハイライトの各ページは、同じコアを WebAssembly としてブラウザに配信しています。

コアに組み込まれているオープンソースソフトウェアの一覧（ライブラリ名・バージョン・入手先）と、著作権表示を含むライセンス本文は、次のページに掲げています。各ライブラリのソースコードは一覧の「入手先」から入手できます。

OSS ライセンス一覧（handball-toolkit の THIRD_PARTY_LICENSES.md）

この一覧は iOS／Android／Web の配布物に含まれる依存を統合したもので、Web 版（WebAssembly）には含まれないライブラリも載っています。

Android 版のアプリ側の依存

Android 版は、集計コアのほかに次のオープンソースソフトウェアを含みます。

  • AndroidX（Jetpack Compose・Room など）、Kotlin の標準ライブラリ、kotlinx-coroutines、JNA — Apache License 2.0。JNA は Apache License 2.0 と LGPL 2.1 のどちらかを選べ、Apache License 2.0 で受けています。
  • desugar_jdk_libs（Android 7 で日付と時刻の処理を動かすための、OpenJDK の一部）— GNU General Public License version 2 with the Classpath Exception。ソースコードは google/desugar_jdk_libs から入手できます。

ゴール枠検出モデル（iOS アプリ）

iOS アプリが端末内の動画を解析するときにゴール枠を見つけるモデルは、D-FINE（Yansong Peng, Hebei Li, Peixi Wu, Yueyi Zhang, Xiaoyan Sun, Feng Wu）の COCO 学習済みの重み ustc-community/dfine-nano-coco を元に、ハンドボールの試合映像でゴール枠を検出するよう追加学習し、Core ML へ変換したものです。元の重みは Apache License 2.0 で配布されています。

アプリに同梱しているもの

iOS アプリと Android 版には、そのアプリに組み込んだ版の著作権表示とライセンス本文を同梱しています。Android 版は v0.3 から、アプリ側の依存についても、ライブラリごとの一覧（名前・版・ライセンス）と本文を同梱しています。上の一覧は最新の版のもので、古いアプリに含まれるライブラリの版とは異なることがあります。過去の版のソースコードも、一覧の「入手先」（crates.io）から入手できます。
